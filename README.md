## 🛠️ Tech Stack & Architecture

This project is built using modern web development practices:

*   **Framework:** [Next.js](https://nextjs.org/) & [React.js](https://reactjs.org/) *(Utilizing SSR & dynamic routing)*
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) *(Utility-first, highly customizable)*
*   **Animations:** [Framer Motion](https://www.framer.com/motion/) *(For smooth, scroll-triggered view transitions)*
*   **Language:** JavaScript / TypeScript fundamentals
*   **Icons:** React Icons

---

## 🚀 Key Features

*   **Server-Side Rendering (SSR):** Ready for complex data fetching and live API integration.
*   **Theme Switcher:** Seamless transition between Dark Mode and Light Mode.
*   **Fully Responsive:** Perfectly adapts to mobile, tablet, and desktop screens using modern CSS grid/flexbox layouts.
*   **Dynamic Tabs:** Interactive experience sections avoiding redundant code mapping (DRY principle).
*   **Performance Optimized:** Clean code architecture focusing on fast load times and minimal re-renders.
